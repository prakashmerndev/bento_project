# Portfolio Website

A simple and modern portfolio website made using HTML and CSS.

This project is inspired by a creative portfolio design. It includes an About Me section, profile image, portfolio heading, project cards, clients, awards, and other information.

## Preview

The website has a clean grid-based layout with:

- About Me section
- Profile image
- Name and email
- Circular portfolio badge
- Portfolio heading
- Project image
- Projects count
- Awards section
- Clients section
- Global Design Awards section

## Technologies Used

- HTML5
- CSS3
- CSS Grid
- CSS Flexbox
- Remix Icon

## Features


- Modern portfolio design
- CSS Grid based structure
- Flexbox for alignment
- Circular profile design
- Image cards
- Clean typography
- Simple and reusable CSS
